# CineBook – Project Statement

## Problem Statement

Movie theatre ticket booking involves managing movies, shows, seat availability, customer details, bookings, and cancellations. CineBook provides a simple command-line based system to organize these operations in one application.

## Scope of the Project

The project covers movie and show display, seat availability checking, ticket booking, booking details, booking cancellation, input validation, loyalty points, and local storage of confirmed booking details in a text file.

## Target Users

The system is intended for users who want to simulate basic movie ticket booking operations through a command-line application. It can also be used as an academic demonstration of Java and Object-Oriented Programming concepts.

## High-Level Features

- View available movies and shows.
- Check available seats.
- Book one or more seats.
- Generate a booking ID.
- Calculate the total ticket amount.
- Award loyalty points to regular customers.
- View booking details.
- Cancel bookings and release seats.
- Save confirmed booking details to a local text file.
- Validate common user inputs.
